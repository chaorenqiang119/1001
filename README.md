# 简算 · 网页计算器

一个无依赖的中文网页计算器，使用 HTML、CSS 和 JavaScript 编写。

## 使用方法

下载仓库后，双击 `index.html` 即可使用，无需安装依赖或启动后端。

也可以在仓库目录运行 `python3 -m http.server 8000`，然后访问 http://localhost:8000。

## 功能

- 加、减、乘、除，小数、负数、括号与运算优先级。
- 点击按键或键盘输入：Enter / = 计算，Esc 清空，Backspace 退格。
- 计算完成后，输入运算符接着算，输入数字开始新算式；也可以选中算式进行修改。
- 保存最近 20 条计算历史，点击历史可使用结果继续计算。
- 移动端适配、键盘焦点提示、屏幕阅读器结果播报。
- 除零、括号不匹配、非法表达式和超范围结果提示。

示例：`(2+3)×4` 得到 `20`；`0.1+0.2` 得到 `0.3`。

历史保存在当前浏览器的 localStorage 中，不会上传。浏览器禁用存储时仍可计算，但刷新后不保留历史。

采用 JavaScript 浮点数，结果保留最多 15 位有效数字，适用于日常计算；不用于要求任意精度的财务或科学计算。乘法需明确输入 `×` 或 `*`，例如 `2×(3+4)`。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 页面样式与手机适配 |
| `calculator.js` | 独立的表达式解析器，不使用 eval |
| `app.js` | 按键、键盘和历史记录交互 |
| `calculator.test.js` | 计算逻辑测试 |

## 测试

安装 Node.js 18 或更新版本后运行：

```sh
node --test calculator.test.js
```
